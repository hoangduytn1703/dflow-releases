Cài DFlow trên máy Windows

Làm lần lượt từ trên xuống, khoảng 15–20 phút. Không cần cài Python, Node hay Git: file cài đã có sẵn mọi thứ DFlow cần.

DFlow_1.5.2_x64-setup.exe
Windows 10 / 11RAM 8 GB trở lênỔ cứng trống ~10 GB
⬇ Tải DFlow 1.5.2 Trang tải (luôn có bản mới nhất)

Chuẩn bị trước

  • Google ChromeDFlow điều khiển Google Flow qua Chrome
  • Google Flow gói Pro hoặc UltraTạo ảnh, video. Vào flow.google.com bằng tài khoản Google có gói Google AI Pro / Ultra
  • Claude gói Pro hoặc MaxAI viết kịch bản, bài viết, trợ lý (gói miễn phí không dùng được)
  • Gemini API keyMiễn phí. Bấm “Create API key”, chép chuỗi bắt đầu bằng AIza…
  • Từ người quản lý DFlowTên đăng nhập + mật khẩu và dòng kết nối dữ liệu (bắt đầu bằng postgresql://). Dòng này giữ bí mật, không gửi cho ai khác.

Các bước cài

  1. Cài DFlow

    Chạy file vừa tải. Nếu Windows hiện màn hình xanh “Windows protected your PC”: bấm More info → Run anyway. Bấm Next tới hết, không cần quyền quản trị.

    Muốn đỡ tốn ổ C thì ở trang Choose Install Location đổi sang ổ D (ví dụ D:\DFlow). Ảnh, video, dữ liệu tự lưu ở ổ D nếu máy có.

  2. Mở DFlow

    Mở DFlow từ menu Start. Lần đầu chờ 20–40 giây.

    Đóng cửa sổ thì DFlow vẫn chạy ngầm ở khay (góc dưới phải, cạnh đồng hồ) để lịch đăng bài vẫn chạy. Tắt hẳn: chuột phải biểu tượng DFlow → Thoát DFlow.

  3. Dán dòng kết nối dữ liệu

    Ở trang đăng nhập, bấm 🌐 Dán dòng kết nối trước → dán nguyên dòng người quản lý gửi → Kết nối.

    DFlow tự kiểm tra rồi khởi động lại (20–40 giây). Chỉ làm một lần trên mỗi máy.

    Bỏ qua bước này thì đăng nhập sẽ báo “Sai tên đăng nhập hoặc mật khẩu” dù gõ đúng.

  4. Đăng nhập và đổi mật khẩu

    Đăng nhập bằng tên + mật khẩu được cấp. Sau đó bấm Đổi mật khẩu ở góc dưới trái (cạnh tên của bạn) để đặt mật khẩu riêng.

  5. Cài Claude Code

    Bấm Start, gõ powershell, mở lên rồi dán lệnh này, Enter:

    irm https://claude.ai/install.ps1 | iex

    Cài xong, đóng PowerShell, mở lại, gõ claude rồi Enter → trình duyệt mở ra để đăng nhập tài khoản Claude → quay lại gõ /exit.

    Gặp lỗi khi cài: xem hướng dẫn chính thức của Claude Code.

  6. Mở Google Flow

    Trong Chrome vào flow.google.com, đăng nhập tài khoản có gói Pro / Ultra, tạo một project mới. Để tab này mở mỗi khi dùng DFlow.

  7. Cài extension DFlow Bridge vào Chrome

    Trong DFlow mở ⚙ Cài đặt → 🖥 Máy này, phần Extension DFlow Bridge:

    • Bấm 📂 Mở thư mục extension (để biết thư mục cần chọn).
    • Trên Chrome gõ vào thanh địa chỉ: chrome://extensions
    • Bật Developer mode (góc trên phải) → Load unpacked → chọn thư mục vừa mở.
    • Quay lại tab Flow, bấm F5.

  8. Cài đặt trong DFlow

    • Hộp AI Providers hiện lên lần đầu: chọn Claude cho cả ba mục → Áp dụng thay đổi.
    • 🖥 Máy này: chọn gói Pro hoặc Ultra giống gói Flow của bạn.
    • 🔑 Gemini key: dán Gemini key.
    • ⚡ Google Flow: chọn project vừa tạo.

Xong. Vào Clip của tôi → Clip mới để làm clip đầu tiên. Gặp chỗ nào không hiểu thì bấm nút tròn 🤖 góc dưới phải và hỏi Trợ lý AI.

Cập nhật bản mới

DFlow tự báo khi có bản mới (thanh “🎉 Có bản DFlow …” ở dưới màn hình). Bấm ⬇ Cập nhật ngay: app tự tải, đóng, cài và mở lại; dữ liệu và đăng nhập giữ nguyên. Sau đó vào chrome://extensions bấm nút tải lại (↻) ở ô DFlow Bridge.

Kiểm tra tay: ⚙ Cài đặt → 🖥 Máy này → ↻ Kiểm tra cập nhật. Bản trước 1.5.1 chưa tự cập nhật được: tải file mới nhất ở trang tải rồi cài đè.

Chỉ cài khi cần

Tải video từ link

Cho link TikTok, YouTube, Instagram, Facebook (Douyin không cần). Dán vào PowerShell, xong tắt DFlow mở lại:

winget install -e --id yt-dlp.yt-dlp --accept-source-agreements --accept-package-agreements

Lồng tiếng video

Cần bộ VieDub cài riêng (nặng, nên có card đồ hoạ NVIDIA). Hỏi người quản lý DFlow để được hướng dẫn.

Edit auto CapCut

Cài CapCut bản máy tính, mở và tạo thử một dự án trước khi dùng.

Tự đăng lên Facebook Page

Cần mã truy cập (token) của Page, dán ở Kênh của tôi. Hỏi người quản lý DFlow cách lấy.
